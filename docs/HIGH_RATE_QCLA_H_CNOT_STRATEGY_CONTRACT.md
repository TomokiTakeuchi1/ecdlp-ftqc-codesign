## Scope and claim boundary

This task first compares three logical handling rules for H and CNOT under the
reviewed direct-CCZ correction-frame convention. It then separates that
logical choice from four code-side implementation families: application
co-design, global/SIMD transversal instructions, gate teleportation through
PPMs, and addressable surgery/code deformation.

- **PROVED:** the six logical rows below follow algebraically from the fixed
  state convention and the `X/Z/CNOT/CZ` frame normal form.
- **NUMERICAL:** OOP/IP width-256 gate, source-layer, and idealized added-layer
  counts are regenerated from the reviewed circuit builders.
- **LITERATURE:** the H-SWAP, tCNOT, automorphism, and measurement-CNOT
  semantics and source-domain timings are transcribed from their cited
  sources.
- **NUMERICAL:** the self-derived one-bit H-teleportation identity is verified
  as an operator on all four measurement branches rather than attributed to a
  literature figure.
- **CHECK:** the RASCqL millisecond arithmetic is an explicitly incompatible
  same-source-domain comparator, not a direct-CCZ runtime.
- **OPEN:** no implementation option is admitted by the current finite
  high-rate backend. Current-backend logical cycles, seconds, physical qubits,
  and failure probability remain null.

## One state/frame convention

The stored correction-to-apply is `C`, and the physical state is

\[
  |\psi_{\mathrm{phys}}\rangle=C^\dagger|\psi_{\mathrm{logical}}\rangle.
\]

For a desired logical Clifford `U`, the three strategies are therefore:

| Strategy | Physical action | New stored frame |
|---|---|---|
| Clifford-conjugated logical | apply `C^dagger U C` | `C_out = C` |
| bare logical | apply `U` | `C_out = U C U^dagger` |
| Clifford-frame tracking | apply identity | `C_out = U C` |

A later logical Pauli `P` is measured physically as
`C_out^dagger P C_out`. The comparison below is about that presented
observable, not only the abstract logical gate.

## Six-way logical comparison

| Gate | Strategy | Direct-CCZ phase-1 data PPM | Y risk in later data PPM | Main cost moved to |
|---|---|---|---|---|
| H | Clifford-conjugated logical | **Z-only remains PROVED** | no, downstream frame unchanged | physical realization of possibly branch-dependent `C^dagger H C` |
| H | bare logical | **not guaranteed Z-only** | yes | conjugated output frame `H C H`; safe only for special incoming frames |
| H | Clifford-frame tracking | **not guaranteed Z-only** | yes | future PPMs and a mandatory H-materialization boundary |
| CNOT | Clifford-conjugated logical | **Z-only remains PROVED** | no | physical realization of possibly dense, branch-dependent `C^dagger CNOT C` |
| CNOT | bare logical | **Z-only remains PROVED** | no | one addressable CNOT now; support is rerouted in `CNOT C CNOT` |
| CNOT | Clifford-frame tracking | **Z-only remains PROVED** | no | larger/branch-dependent future Z support and later materialization |

The phase-2 single-resource measurements remain X-only in all six rows: the
resource values are globally fresh, do not enter the data correction frame,
and are consumed after their one readout.

### Why CNOT is axis-safe

Let `G_Z` be the Clifford subgroup generated by `X`, `Z`, `CNOT`, and `CZ`.
Every element of `G_Z` maps a Z-type Pauli to another Z-type Pauli. Since
`CNOT` is itself in this group:

- retaining `C` leaves the invariant unchanged;
- `CNOT C CNOT` remains in `G_Z`; and
- `CNOT C` remains in `G_Z`.

Thus all three CNOT strategies preserve the existing Z-only phase-1 proof.
They do **not** preserve support size or routing cost. The prior support audit
already shows that support can be outcome-dependent.

### Why H is different

H exchanges X and Z. Retaining `C` by physically implementing
`C^dagger H C` preserves the existing downstream invariant, but bare or
tracked H changes the stored frame outside `G_Z` in general.

An explicit two-qubit witness is stored and regression-tested. Take the old
stored circuit `[CNOT(t->c), CZ(c,t)]` and a future `Z_t` measurement. Appending
H to the frame, or using the bare-H update `H C H`, presents a Pauli with Y on
both `c` and `t` (up to sign). This is stronger than merely observing an X/Z
swap: a generic incoming frame can create actual Y content.

Consequently, a native bare H-SWAP or one-bit H teleportation does not by
itself implement the current Clifford-conjugated-H policy. It first needs one
of:

1. materialize/clear the incoming frame;
2. prove that the actual target-local incoming frame is H-safe; or
3. co-design the entire conjugated H or direct-CCZ event as one instruction.

## PPMs added by gate teleportation

The H row below is a self-derived identity with an exact all-branch operator
check. The CNOT row is the reviewed Xu-et-al. Figure 11(c) identity.

| Gate | Provisioned stabilizer ancilla | Ordered measurements | Added axis issue |
|---|---|---|---|
| H | one `|0>` output carrier | `ZX`, then destructive input `X` | contains a mixed-axis `ZX` PPM; no Y in the bare gadget |
| CNOT | one `|+>` scratch | `ZZ`, `XX`, then destructive scratch `Z` | each stage is pure Z or pure X; the three stages are sequential |

Neither gadget consumes a T or CCZ magic state. Their outcomes produce Pauli
corrections and carrier rebinding. The H gadget's `ZX` makes it unsuitable for
a backend that supports only Z-type data PPMs, unless that backend separately
admits mixed-axis PPMs. The CNOT gadget fits a Z/X-only staged interface, but
needs one live scratch per simultaneous CNOT.

For the H gadget, outcome bit zero denotes the `+1` eigenspace. Exact
projector reconstruction checks all four `(ZX, X)` branches. Every branch has
probability `1/4`; corrections `I`, `X`, `Z`, and `ZX` (the last equal to Y up
to phase) recover ideal H with operator residual below `1e-12`. This is
`NUMERICAL` verification of a self-derived identity, not a source claim about
Xu et al. Figure 11. Xu Figure 11(c) remains the source for measurement CNOT.

## QEC execution options

### H

| Option | Online logical primitive depth per H layer | Logical ancilla/resource | Addressability and QEC obligation |
|---|---:|---|---|
| co-design whole conjugated-H/direct-CCZ event | 0 stand-alone H layers, conditionally | instruction-specific; direct-CCZ state remains separate | must prove the full event automorphism/code switch, distance preservation, and branch handling |
| global/SIMD H-SWAP | 1 | no magic state | H on every logical lane plus logical transpose; requires target packing, permutation tracking, and dummy/known occupants |
| one-bit H teleportation (`NUMERICAL`, self-derived) | 2 ordered PPM layers | one provisioned `|0>` output per H | arbitrary target if `ZX` and `X` are native; directly implements bare H, not `C^dagger H C` |
| addressable deformation/surgery H | 1 parameterized gadget layer | code-specific stabilizer workspace | no generic high-rate-qLDPC construction or cycle count is admitted |

The published RASCqL Table 2 value `1.9 ms` applies to its global H-SWAP on
the `[[450,32,8]]` HGPS/RNAA system. Appendix C.3 states that the action is H
on all logicals plus logical transpose. It is not an arbitrary subset H.

### CNOT

| Option | Online logical primitive depth per CNOT layer | Logical ancilla/resource | Addressability and QEC obligation |
|---|---:|---|---|
| co-design the complete GF(2) layer as an automorphism | 0, if exact ISA membership holds | none | test each QCLA layer matrix; audit rate, check weight, distance, and later relabel debt |
| blockwise SIMD transversal CNOT | 1 | no scratch, but paired encoded blocks/dummy lanes | maps corresponding logical pairs; requires pair packing, basis alignment, movement, and correlated decoding |
| measurement CNOT / PPM surgery | 3 ordered PPM layers | one provisioned `|+>` scratch per CNOT | arbitrary pair only if `ZZ`, `XX`, and `Z` supports are native and enough ports/scratch exist |

RASCqL's autoCNOT and dirty shifts are zero-time virtual operations only for
its embedded patterns. Its tCNOT value is `3.0 ms`, with up to `2.4 ms` of
deferred physical-relabel cost before a later tCNOT. Neither number is a
generic high-rate CNOT cost.

These are `NUMERICAL` logical-layer envelopes, not QEC cycles. In particular,

replace the current frame-conjugated-H semantics.

For finite timing, let `L_T` be the number of Toffoli-bearing layers and
`L_C` the number of CNOT-bearing layers. Then:

\[
\begin{aligned}
\Delta T_{H,\mathrm{strict}} &= 2L_T\tau_H,\\
\Delta T_{H,\mathrm{overlap}} &= L_T[\tau_H+\max(0,\tau_H-\tau_{rX})],\\
\Delta T_{Htel,\mathrm{strict}} &= 2L_T(\tau_{ZX}+\tau_X+\tau_{react,H}),\\
\Delta T_{CNOT,SIMD} &= L_C\tau_{tCNOT},\\
\Delta T_{CNOT,tel} &= L_C(\tau_{ZZ}+\tau_{XX}+\tau_Z+\tau_{react,CNOT}).
\end{aligned}
\]

Offline preparation becomes an explicit extra term if it cannot be hidden or
provisioned.

## RASCqL source-domain comparator

Using only Table 1/2 values from the RASCqL `[[450,32,8]]` HGPS/RNAA domain,
assuming unlimited block-level concurrency, ignoring the optional `2.4 ms`
relabel debt, and treating its `0.5 ms` global X measurement as the resource-X
overlap partner gives:

| Added H-SWAP + tCNOT time | clean OOP | in-place |
|---|---:|---:|
| all H layers serialized | 73.6 ms | 141.2 ms |
| closing H-SWAP overlaps resource-X | 65.1 ms | 124.2 ms |

This arithmetic is `CHECK`, not a runtime result. The paper's QEC cycle is
`3.9 ms`, but the table's `1.9/3.0/0.5 ms` instruction values are physical
execution times, not integer multiples supplied for the present direct-CCZ
backend. The paper does not provide the direct-CCZ consumer, arbitrary subset
H, QCLA placement, or branch-dependent PPM mapper needed to compose the
figures with the 34/68 levels.

For a 32-logical SIMD block, optimistic perfect packing alone would require:

| Packing quantity | clean OOP | in-place |
|---|---:|---:|
| H-SWAP block invocations over opening and closing layers | 92 | 184 |
| peak simultaneous H-SWAP blocks | 8 | 8 |
| unused H lane-invocations | 486 | 972 |
| tCNOT block-pair invocations | 24 | 32 |
| peak simultaneous tCNOT block pairs | 8 | 8 |
| unused CNOT pair-lanes | 2 | 5 |

These are packing lower-envelope counts. They assume logical values can be
placed into exactly the required lanes at no cost; the actual mapper can need
more blocks, movements, or time.

## Design conclusion and next discriminator

The current logical default remains:

- **H:** Clifford-conjugated logical, because this alone preserves the proved
  Z-only phase-1 invariant for a general incoming correction frame;
- **CNOT:** bare logical, because it preserves that same invariant while
  avoiding synthesis of `C^dagger CNOT C` and adds only 3/4 source layers
  before QEC expansion.

The most useful next experiment is not a generic Clifford benchmark. It is a
code-specific mapper test with two independent questions:

1. Does the selected automorphism/SIMD ISA generate each of the 3 OOP or 4 IP
   CNOT-layer GF(2) matrices, including the required placement permutations?
2. Can each of the 34/68 H target masks be packed into global H-SWAP blocks,
   or can the entire frame-conjugated H/direct-CCZ event be embedded without
   introducing mixed/Y PPMs?

Until one of these closes, the finite high-rate runtime remains `OPEN`.
