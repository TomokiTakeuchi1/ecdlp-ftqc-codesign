## Reviewer findings

This is the mathematically deepest submission in this task line: it claims a
`PROVED` generator-closure theorem that closes width-256 candidate
compatibility without materializing a pair table, which is a genuinely new
mathematical result rather than a reuse or scaling of previously reviewed
math. The review therefore went beyond structural/reproducibility checking
into independent mathematical verification of the claim itself, at two
levels: an abstract matrix-level proof of the generator-closure theorem, and
an independent structural check that the actual codebase's data satisfies the
theorem's premises at every tested width including 256.

1. **Scope confirmation.** `git diff --stat` confirms this task adds one new
   module (`direct_ccz_ppm_compatibility_certificate.py`) plus its replay,
   and touches only `scheduler/__init__.py` / `verification/__init__.py` with
   purely additive exports. No previously reviewed compiler, architecture, or
   batching code is modified.
2. **Independent matrix-level verification of the core theorem.** Wrote a
   from-scratch numpy script (no import of the reviewed
   `SymbolicPauliWord.apply_gate` or any project code) that builds explicit
   2/3-qubit unitary matrices for X, Z, CNOT, and CZ and exhaustively
   conjugates every "Z-type" Pauli operator (only `I`/`Z` on each qubit) by
   every instance of each generator. All 148 exhaustive test cases confirm
   the output is always classifiable as another Z-type Pauli string — the
   generator set is genuinely closed on this subspace. The same script
   confirms H is the one primitive that breaks closure (H conjugation of `Z`
   produces `X`, exactly as the contract's "no deferred H" premise requires),
   and independently confirms that any two Z-type Pauli operators
   automatically commute (28 pairs on 3 qubits, zero violations) and can
   never carry Y content. This directly and independently substantiates the
   contract's central claim ("X/Z do not change axes; CNOT maps Z-type to
   Z-type; CZ fixes Z-type; conditional selection therefore preserves
   branchwise Z-type") from first principles, not by trusting the docstring.
3. **Independent structural verification that the codebase's actual data
   satisfies the theorem's premises**, using a second from-scratch script
   that imports only the already-reviewed `ecdlp_ftqc.circuits` trace
   builders and `ecdlp_ftqc.compiler` event-lowering functions (never the
   reviewed certifier module), and independently re-derives — with different
   code — every premise the certificate checks: (a) no resource value is
   reused or aliases a source logical value, (b) every event has exactly
   3 ZZ + 3 X PPMs, (c) every deferred correction generator is CZ/Z/X and
   never H, (d) every correction's support is confined to the event's own
   data qubits and never touches a resource qubit, (e) every source
   algorithmic layer has pairwise-disjoint logical support, (f) every source
   dependency strictly advances the layer, and (g) passthrough source gates
   are only X/CNOT. Ran this at widths 5, 8, 17, and 256 for both variants —
   56 independent checks, zero failures, including the width-256 case with
   1,229/2,458 events and 3,955/8,404 dependencies.
4. **Hand-verified combinatorics.** Independently recomputed the OOP width-5
   within-batch pair count from the reviewed batch-size sequence
   (`12,12,3,3,6,6,3,3,3,3,3,3`) via `sum(n*(n-1)/2)` and got exactly 186,
   matching `exact_anchor_equivalences[0].materialized_intra_batch_pair_count`
   in the generated `summary.json`.
5. **Fail-closed behavior.** Read the falsification tests
