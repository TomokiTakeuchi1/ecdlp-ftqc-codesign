### F1. Analytic check (primary evidence)

Derived from the stated conventions (`H_X = B(d1)`, `H_Z^T = B(d2)`), not
by re-reading the note's sentences:

1. **Helper state and signs.** `S = S_X^h = im d1''^T` is contained in
   `C_h = ker H_Z^h = (S_Z^h)^perp` by the CSS condition, so
   `|S|^{-1/2} sum_{v in S} |v>` has every Z stabilizer `+1`; every helper
   logical Z rep lies in `ker d1'' = S^perp`, so every logical Z is `+1`.
   All amplitudes are positive.
2. **Orientation.** With data controls and helper targets, target `v`
   receives `sum_{u: F_uv=1} x_u = (F^T x)_v`, so `U_F|x,v> = |x, v+F^T x>`
   with `F = B(eta_1)` (data rows, helper columns). Correct.
3. **Inclusions.** `F d2'' = d2 (iota (x) I)` gives `F S_Z^h <= S_Z^D`;
   `F^T d1^T = (d1 F)^T = (eta0 d1'')^T = d1''^T eta0^T` gives
   `F^T S_X^D <= S_X^h`; then `(F^T x).s = x.(F s) = 0` for `x in C_D`,
   `s in S_Z^h`, so `F^T C_D <= C_h`.
4. **Eq. (6).** `U_F` is a permutation and the helper amplitudes are all
   `|S|^{-1/2}`, so `K_y|x> = |S|^{-1/2} 1{y + F^T x in S}|x>` exactly,
   with no phase. `K_y` is diagonal in the computational basis.
5. **`ker L = S`.** The no-residual-sector property of the shortening lemma
   gives `S_Z^h + span{z_h,j,m} = ker d1'' = S^perp`; a `w in C_h` with zero
   L is orthogonal to that whole space, hence in `S^perp^perp = S`. With
   `dim C_h / S = k_h = q`, L is onto and every fiber has `|S|` strings.
   Uncoupled helper coordinates (the `e_new (x) R^b` block, killed by
   `p (x) I_b`) are inside these fibers, as the note says.
6. **Projector identity.** For `x in C_D`, `L(F^T x)_{j,m} = (F z_h,j,m).x`,
   the binary eigenvalue of `P_j,m = Z(F z_h,j,m)` on `|x>`; the label is
   representative-independent because Z stabilizers pair to zero with
   `C_D`. So the indicator equals the diagonal of `Pi_b(y)` on `C_D`, and
   since every state of Q is supported on `C_D`, (4) holds with the stated
   scalar; records outside `C_h` give zero.
7. **Instrument and scope.** Summing `|S|` equal Kraus terms per fiber gives
   (5); the identity is an operator identity, so the reference extension is
   immediate. Independence of the `P_j,m` (distinct merged basis classes)
   makes all `2^q` projectors nonzero on Q. The information/disturbance
   paragraph is correct: fine records carry no state-dependent information
   beyond `b`; `X3`, `Z3` and `X1 X2` commute with every projector; the
   family-3 conditioning caveat is stated honestly; `s*l` products, not one.
