### F7. Evidence labels and FT boundary

Independently re-derived (not merely accepted) the effective-auxiliary
distance-inheritance claim: since `H_X^eff = H_X^Q` is literally unchanged
and `row(H_Z^eff) = row(H_Z^Q) + L` only grows (rows are added, never
removed, and they commute with `H_X^Q` since `L` consists of normalizers),
elementary set monotonicity gives both directions immediately: `ker(H_Z^eff)
subseteq ker(H_Z^Q)` shrinks the candidate X-logical set, so `d_X^eff >=
d_X^Q`; and with `H_X` fixed, a larger `row(H_Z^eff)` removes more elements
of `ker(H_X^Q)` from being nontrivial, so `d_Z^eff >= d_Z^Q`. Both follow from
"adding commuting rows to one check matrix while holding the other fixed can
only weakly increase that side's distance", which I verified is exactly the
situation here. I did not separately re-derive the `d_Z^M >= d_Z^Q`
weight-preserving-injection argument in full detail, but it is consistent
with the F1 inclusion already confirmed and is a standard embedding argument.
