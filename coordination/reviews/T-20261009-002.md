### F1. Analytic check (primary evidence)

1. **Eq. (4), original binary coordinates.** Every ring entry of
   `diag(iota (x) I_{s+b}, p (x) I_b)` is the constant 0 or 1, so its binary
   expansion consists of identity and zero blocks: each helper qubit maps to
   at most one data qubit, and distinct helper qubits map to distinct data
   qubits. `iota (x) I` relabels the first block injectively;
   `p (x) I_b` keeps the `e_1..e_a` rows of the second block and kills the
   `e_new (x) R^b` rows. The two output blocks are different summands, so
   `wt(Fz) = wt(u) + wt(v_old) = wt(z) - wt(v_new)` holds for every binary
   `z`, with no `V^{-1}`/`T^{-1}` basis change involved. F is not
   physically injective, as stated.
2. **Well-defined class map.** `d1 F = eta0 d1''` sends `ker d1''` (helper Z
   cycles, `ker H_X`) into `ker d1`; `F d2'' = d2 eta2` sends `im d2''`
   (helper Z stabilizers) into `im d2`. So `F_*` is well defined.
3. **Injectivity.** At r=3 the approved shortening lemma gives the whole
   helper Z basis as the merged classes `[z_h,j,m]`, with no residual sector;
   `F_*[z_h,j,m] = [z_1,j,m] + [z_2,j,m]`. A nonzero combination has the same
   nonzero coefficient vector on family 1 of the independent data basis
   (`ker A (x) coker B`), so it is nonzero. Hence `F_*` is injective.
4. **All representatives, direction of (6).** For any helper cycle `z`
   outside the helper stabilizers, `[z] != 0` implies `F_*[z] != 0`, so `Fz`
   is a data cycle outside the data stabilizers. Stabilizer dressing,
   including second-block support, is covered because the argument is
   applied to every such `z`, not only canonical generators. Then
   `d_Z(Q) <= wt(Fz) <= wt(z)`; minimizing over `z` gives `d_Z(Q_h) >= d_Z(Q)`.
   `k_h = s*l > 0` makes the helper minimum well defined.
