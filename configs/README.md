# Configuration policy

Use versioned, human-readable configuration files. A committed result must refer to immutable configuration IDs or committed file hashes.

Directories:

- `algorithms/`: circuit-generation and arithmetic choices;
- `architectures/`: processor, memory, routing, and controller choices;
- `codes/`: code parameters and logical-operation capabilities;
- `factories/`: resource-state production and buffering;
- `experiments/`: compositions of the above.
