# Benchmarks

- `circuits/`: small canonical circuits or references to generators.
- `traces/`: canonical semantic traces.
- `configs/`: benchmark-specific configurations.
- `expected/`: hand-checked or independently validated expected outputs.
- `results/`: generated outputs, ignored by Git except `.gitkeep`.

Every benchmark must state whether it checks semantics, scheduling, resource counts, reliability, or end-to-end reproducibility.
